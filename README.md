# 🎭 Srijan ’24 Mobile App

The official Android application for **Srijan ’24**, the annual cultural fest of **IIT(ISM) Dhanbad**. Developed using **Kotlin**, the app enabled participants to register for events, make secure payments, and stay updated with real-time notifications.

---

## 🚀 Features

- 📋 **Event Registration**
    - Seamless registration for **20+ events and activities**
    - User-friendly UI for browsing events and submitting details

- 💳 **Secure Payments**
    - Integrated **Razorpay API** for hassle-free and secure transactions
    - Successfully processed **₹1,00,000+** in payments

- 🔔 **Real-time Notifications**
    - Integrated **Firebase Cloud Messaging (FCM)** to send updates and alerts

- 📱 **Modern Android Development**
    - Built with **Kotlin** and **Android SDK**
    - Follows **MVVM Architecture** for clean code and maintainability
    - Network operations handled via **Retrofit**

---

## 🧱 Tech Stack

- **Language:** Kotlin
- **Architecture:** MVVM (Model-View-ViewModel)
- **Backend Integration:** Retrofit
- **Payments:** Razorpay API
- **Push Notifications:** Firebase Cloud Messaging (FCM)
- **Android SDK:** Jetpack Components, Material Design
